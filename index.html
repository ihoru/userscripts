DuoCards · Vocabulary import

DuoCards Auto Import

Import words without saving every card by hand. Waits for the picture and usage example, saves the card, and resets progress for words already in your vocabulary.

Works in the main card screen and book editor, with a Pause button and a log of completed actions.

How to use

  1. Get Tampermonkey

    Install the Tampermonkey browser extension. In Chrome, enable “Allow User Scripts” if prompted.

  2. Choose a script

    Click Install / update above, review the script, and confirm installation in Tampermonkey. If the link displays code, use Dashboard → Utilities → Import from URL with that link.

  3. Use the website as usual

    Reload the target website after installation or an update. Tampermonkey checks for future updates automatically on its normal schedule when update checks are enabled.

Already installed an older DuoCards ZIP version or GitLab → TopTracker 0.1.0? Click Install / update once to enable future updates. Finish any active DuoCards import before reloading so you don’t lose its queue.
